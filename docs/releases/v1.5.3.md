# JustRayzist v1.5.3

![LoRA library preview](../../readme_images/lora_preview.png)

- Replaces the custom in-memory LoRA multipart parser with streamed multipart handling so `.safetensors` uploads no longer require buffering the whole body in memory.
- Preserves uploaded LoRA bytes exactly, adds explicit `10 GiB` limits for LoRA weights and `10 MiB` limits for thumbnail uploads, and cleans up partial draft artifacts on upload failure.
- Adds `POST /gallery/rebuild` for client-scoped gallery reconciliation after manual PNG copies, replacements, or deletions in the gallery folder.
- Narrows managed gallery indexing back to PNG-only so sync, import, and direct image serving match the actual storage contract again.
- Restores release/readiness hygiene by tracking `models/upscaler/README.md`, ignoring local LoRA sidecars/previews, and keeping packaged setup checks aligned with the new multipart dependency.
