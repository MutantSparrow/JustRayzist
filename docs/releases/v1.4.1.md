# JustRayzist v1.4.1

- The web gallery now uses the new masonry layout by default, with queue recovery after refresh, per-job cancel controls, and single-select color swatch filtering.
- Gallery color filtering now uses cached dominant-color classification in the SQLite index, with a one-time background rebuild after classifier updates instead of reprocessing the whole gallery on every click.
- Prompt enhancement is stronger and more style-faithful, and long prompts are fit to the encoder budget instead of being accepted and then silently chopped downstream.
- The Euler scheduler path was hardened so low-creativity generations no longer inherit invalid scheduler state after DPM runs.
- Client-scoped job controls and gallery flows are broader and cleaner, including active job cancel, ZIP download, gallery import/delete, and refreshed `/API` examples generated from the live route manifest.
