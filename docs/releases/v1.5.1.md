# JustRayzist v1.5.1

![LoRA library preview](../../readme_images/lora_preview.png)

- Fixes the packaged in-place updater for `v1.5.x` releases by replacing destructive directory deletion with in-place managed directory mirroring, avoiding Windows failures when roots like `app/` cannot be removed during self-update.
- Preserves the intended packaged update behavior: local `models/`, `outputs/`, `data/`, and `.venv/` remain untouched while tracked app files are refreshed from the selected release asset.
- Keeps the full `v1.5.0` feature set intact, including managed LoRA library support, the gallery/fullscreen action refresh, layout cleanup, and broader Z-Image LoRA compatibility fixes.
