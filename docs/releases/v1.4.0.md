# JustRayzist v1.4.0

- Startup is simpler: normal users no longer choose runtime profiles, pack choice is skipped when only one public enabled pack is installed, and memory strategy is auto-detected from available VRAM.
- Setup now auto-selects the default model variant: BF16 stays the default on higher-VRAM systems, while sub-13GB NVIDIA installs switch to `Rayzist_fp8_full`.
- Real FP8 packs are now supported as normal packs with BF16 compute plus FP8-at-rest preservation where safe. Native FP8 inference is not part of this release.
- Pack handling is cleaner: public discovery now respects `user_visible` and `enabled`, constrained runs can derive internal `__auto_fp8_storage` variants, and minimal compatible packs can inherit shared defaults from `Rayzist_bf16`.
- The API surface and docs are more complete, including ZIP download, gallery import/delete flows, and generated `/API` examples sourced from the live route manifest.
- Engineering tooling now includes stronger validation and comparison workflows such as `pack-compare`, `pack-compare-suite`, `prompt-grid-benchmark`, and expanded FP8/runtime coverage in the test suite.
