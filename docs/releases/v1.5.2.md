# JustRayzist v1.5.2

![LoRA library preview](../../readme_images/lora_preview.png)

- Fixes a LoRA runtime regression where adapters could remain globally disabled after cleanup, causing runs with different LoRA weights, stacked LoRAs, or even no LoRA to collapse into the same image output.
- Restores effective LoRA weight application by re-enabling adapters after `set_adapters(...)` while keeping the stale-adapter cleanup path that prevents "adapter name already in use" failures.
- Expands the supported LoRA weight range to `-2.0` through `+2.0` in `0.25` steps, matching the current drawer slider behavior and API validation.
- Keeps the managed multi-LoRA library flow, gallery/fullscreen action refresh, layout cleanup, and packaged updater fixes from `v1.5.0` and `v1.5.1`.
