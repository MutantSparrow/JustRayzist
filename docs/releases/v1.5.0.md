# JustRayzist v1.5.0

- Managed LoRA support lands across the app: staged safetensors upload, editable metadata and trigger words, stored previews, session-scoped multi-LoRA application, and LoRA details saved into output metadata and fullscreen preview.
- The LoRA library UI was rebuilt around a proper right-side drawer and authoring modal, with progress-aware uploads, a compact preview grid, per-LoRA strength presets, and cleaner save/apply behavior.
- Z-Image LoRA compatibility is substantially broader in this release, including offline local loading fixes, legacy and lora_unet conversion, qkv splitting, diffusion_model-prefixed native adapters, and quieter intentional multi-adapter loading.
- Gallery and fullscreen actions were normalized around a shared icon-button system, with multiselect controls, fullscreen delete/use/download/upscale actions, and confirmation dialogs all aligned visually and behaviorally.
- Launcher and runtime polish includes the model-pack selection fix, corrected dtype handling in the Z-Image pipeline factory, refreshed generated API docs, and focused tests around LoRA loading, metadata persistence, and updated UI flows.
