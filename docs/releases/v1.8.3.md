# JustRayzist v1.8.3

- Adds best-effort compatibility for extracted Z-Image LoRAs that omit matching `.alpha` tensors and include additive `.diff` / `.diff_b` parameter deltas.
- Keeps stacked multi-LoRA behavior intact by applying extracted direct deltas outside PEFT and fully reverting them when adapters clear.
- Adds local-only `POST /server/restart`, API manifest/docs coverage, and API page restart control so the app can reboot in place and pick up backend changes without manual relaunch.
