# JustRayzist v1.7.2

- Adds end-to-end `img2img` support across UI, API, and CLI, including source-image lineage metadata and cancellation-aware pending jobs.
- Adds fixed-FS `clarity` processing for gallery images plus `clarity-compare` CLI diagnostics with contact sheets and CSV/JSONL reports.
- Hardens `POST /server/kill` so only callers on the local machine can shut down the app.
- Fixes packaged `justrayzist-web` startup so the launcher again reaches the live FastAPI server path.
