# JustRayzist v1.8.7

## Summary

Adds Rayzist Chat as a right-side app drawer and moves Qwen helper text inference into its own backend while preserving existing image generation behavior.

## Changes

- Adds a Rayzist Chat drawer with numbered bubbles, local per-client JSON history, input locking while the encoder is running, and busy spinner feedback while chat waits in the generation lock.
- Adds chat API routes for send, load, and clear history.
- Adds assistant actions for using a prompt, starting a generation, and opening app links such as the API page.
- Grounds chat answers through Rayzist documentation snippets, with app-specific guidance for Wildcards, LoRAs, Prompt Enhancer, Clarity, image inference, Creative Mode, R+, image references, gallery scope, and gallery migration tools.
- Moves Qwen chat, prompt enhancement, prompt compression, wildcard suggestions, helper decoding, and action parsing into `diffusers_qwen.py`.
- Adds a Qwen pipeline factory mirror for loading tokenizer and text encoder components without taking ownership of image generation.

## Fixes

- Prevents raw chat action JSON from appearing in assistant bubbles.
- Avoids offering prompt buttons for non-prompt informational answers.
- Corrects assistant grounding for Clarity so it is described as post-generation image refinement, not prompt rewriting.
- Improves RAG matching for short `R+` questions and gallery client scope questions.

## Packaging

- CUDA lane baselines are unchanged.
- Release artifacts remain bootstrap packages for `cu128` and `cu126`.
- Model pack format is unchanged.

## Tests

- Focused branch and main smoke checks passed.
- Repository readiness check passed.
- Full test suite passed with `326` tests.

## Known issues

No known release blockers.

## Upgrade notes

- Existing models, outputs, and gallery data are preserved.
- Chat history is stored locally under `data/chat` per browser client.
- Users who change browser, browser profile, or server origin may see a different gallery because gallery scope follows the browser client id.
