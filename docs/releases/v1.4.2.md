# JustRayzist v1.4.2

- The gallery now supports persisted favorites end to end, including tile and fullscreen hearts, favorite-only filtering, and API/storage coverage for listing and mutation.
- Gallery interactions are cleaner and more responsive: favorite toggles are optimistic, filter transitions keep short enter/exit feedback without the earlier hang, multiselect no longer forces every tooltip open, and delete/upscale actions now have compact visual cues.
- Browser notifications now fire when image generations complete, making long-running jobs easier to monitor away from the tab.
- Favorites are now documented in the generated API usage docs, and the release also hardens restored client queue state so active non-queued jobs are not duplicated after refresh.
