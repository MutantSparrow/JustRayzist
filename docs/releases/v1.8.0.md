# JustRayzist v1.8.0

- Adds `R+` as a staged alternate inference mode for generation, exposed in the web UI and CLI.
- Adds web controls for `R+` toggle, vibrance, and bias, with UI-side `20`-step locking for consistent runs.
- Adds `rplus-compare` CLI diagnostics plus saved inference metadata so gallery and fullscreen views can show `R+` and Creative Mode context.
- Cleans remaining staging fallout around the `R+` rollout and hardens helper-text generation fallback configuration.
