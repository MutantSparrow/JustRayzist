# JustRayzist v1.7.0

- Adds a full Wildcard Library drawer that matches the LoRA library UX, with live create/edit/delete, editable prompt tokens, multiline entries, and copy-to-clipboard cards.
- Expands `__token__` wildcards before prompt enhancement and LoRA injection, with deterministic per-occurrence selection when the seed is frozen.
- Persists wildcard substitutions in PNG metadata and gallery indexing through `prompt_wildcard_resolved`, `wildcards_json`, and `wildcard_count`.
- Adds encoder-powered wildcard suggestions from theme and format examples, with selection and append flow inside the wildcard editor.
- Fixes the library pull tabs so both LoRA and Wildcard drawers remain visible, labeled, and closable while open.
