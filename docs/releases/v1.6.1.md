# JustRayzist v1.6.1

- Hardens prompt enhancement fallback for very long prompts so explicit style constraints are preserved even when they appear late in the prompt.
- Replaces the unsafe raw original-prompt fallback with tokenizer-aware budget-safe fallbacks, preventing prompt text from overflowing the image pipeline budget during enhancement.
- Adds regression coverage for late-style preservation, seeded style fallback behavior, and single-clause over-budget prompt truncation.
