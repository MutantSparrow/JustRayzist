# JustRayzist v1.8.6

- Adds optional `Rayzist_qwen3_4b_fp8` setup download from [MutantSparrow/qwen3_4b_Rayzist_v1.0_fp8](https://huggingface.co/MutantSparrow/qwen3_4b_Rayzist_v1.0_fp8).
- Loads scaled FP8 Qwen3 text-encoder checkpoints by converting tensors to BF16 at runtime.
- Improves prompt enhancement handling for long prompts by compressing over-budget prompts before generation and avoiding partial trailing fragments.
- Keeps release artifacts bootstrap-only and documents both `cu126` and `cu128` packaging lanes.
